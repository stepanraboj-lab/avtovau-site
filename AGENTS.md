# AutoVau — правила работы с проектом

## О проекте

* Сайт компании по аренде автомобилей в Москве.
* Основной язык сайта — русский.
* Главная цель — получение заявок от клиентов.
* Основной домен — автовау.рф.
* Punycode домена — xn--80aafa3dxak.xn--p1ai.
* Регистратор домена — РУЦЕНТР.
* DNS-провайдер — Cloudflare.
* Хостинг сайта — GitHub Pages.

## Правила работы

* Общаться с владельцем на русском языке.
* Перед изменениями изучать актуальную структуру проекта.
* Учитывать предыдущие изменения и решения.
* Не менять цены, контакты и условия аренды без согласования.
* Не придумывать характеристики автомобилей.
* Сохранять дизайн и мобильную адаптацию.
* Учитывать SEO, скорость загрузки и удобство использования сайта.
* Не удалять рабочие файлы без разрешения.
* Не изменять workflows без согласования.
* Не добавлять платные сервисы без разрешения.
* Не хранить пароли, токены и другие секретные данные в репозитории.
* Работать в отдельной ветке.
* Не отправлять изменения напрямую в main.
* Не объединять Pull Request самостоятельно.
* Не выполнять публикацию вручную без согласования.
* Не вносить изменения, не относящиеся к поставленной задаче.
* При обнаружении дополнительных проблем сначала сообщать о них владельцу.

## Домен, DNS и публикация

* Не изменять настройки DNS, Cloudflare и регистратора без отдельного разрешения.
* Не изменять и не удалять файл CNAME без согласования.
* Не отвязывать пользовательский домен от GitHub Pages.
* Не изменять настройки HTTPS без согласования.
* Не отключать GitHub Pages.
* Не возвращать сайт на Netlify.
* Не создавать дополнительные workflows публикации без необходимости.
* Учитывать, что обновление DNS и выпуск SSL-сертификата могут занимать продолжительное время.
* Не пытаться исправлять временные ошибки распространения DNS изменением кода сайта или настроек публикации.

## Проверка изменений

* Проверять главную страницу.
* Проверять все карточки автомобилей.
* Проверять изображения и ссылки.
* Проверять кнопки и формы заявок.
* Проверять мобильную и десктопную версии.
* Проверять ошибки HTML, CSS и JavaScript.
* Проверять целостность и структуру архива site.zip.
* Проверять наличие CNAME и .nojekyll.
* Проверять отсутствие случайных изменений цен, контактов и условий аренды.
* Не утверждать, что проверка выполнена, если фактически выполнить её не удалось.
